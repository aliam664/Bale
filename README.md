# ربات دوز آنلاین برای پیام‌رسان بله 🎮

ربات (بازوی) بله که دو کاربر را برای بازی **دوز (Tic-Tac-Toe)** با هم جفت می‌کند و امکان **بازی با کامپیوتر** (سه سطح، سطح سخت شکست‌ناپذیر) هم دارد. سرور ربات با **Long Polling** کار می‌کند؛ یعنی روی **کامپیوتر شخصی** و بدون IP عمومی، دامنه یا SSL اجرا می‌شود.

> 📚 **تحقیق کامل دربارهٔ ساخت ربات در بله** (API، محدودیت‌ها، کتابخانه‌ها، معماری پیشنهادی): [`docs/bale-bot-research.md`](docs/bale-bot-research.md)

## امکانات نسخهٔ فعلی (نمونهٔ اولیه)

- `/start` → منوی شیشه‌ای: بازی با حریف آنلاین / بازی با کامپیوتر / راهنما
- **مچ‌میکینگ:** نفر اول وارد صف می‌شود، با ورود نفر دوم بازی فوراً شروع می‌شود (نفر اول ❌ است و شروع می‌کند)
- تختهٔ ۳×۳ با دکمه‌های شیشه‌ای؛ هر حرکت با `editMessageText` در تختهٔ **هر دو** بازیکن منعکس می‌شود
- **کامپیوتر:** آسان (تصادفی)، متوسط، سخت (Minimax)
- تسلیم، بازی مجدد (با تعویض نماد)، `/cancel`
- تایم‌اوت نوبت و تایم‌اوت صف
- سازگاری با کلاینت‌های قدیمی بله که `answerCallbackQuery` ندارند
- بدون پایگاه داده (وضعیت در حافظه) — برای شروع کافی است

## راه‌اندازی

### ۱. ساخت بازو در بله
در بله `@botfather` را باز کنید → «ساخت بازوی جدید» → نام و نام کاربری (ختم به `bot`) → توکن را کپی کنید.

### ۲. نصب
```bash
git clone <این مخزن>
cd Bale
python -m venv .venv
# ویندوز:   .venv\Scripts\activate
# لینوکس/مک: source .venv/bin/activate
pip install -r requirements.txt
```

### ۳. تنظیم توکن
```bash
cp .env.example .env     # ویندوز: copy .env.example .env
# فایل .env را باز کنید و BALE_TOKEN را بگذارید
```

### ۴. اجرا
```bash
python -m bot
```
خروجی باید چیزی شبیه `logged in as @yourbot` باشد. حالا در بله به ربات `/start` بدهید. برای تست مچ‌میکینگ به دو حساب بله نیاز دارید.

> فقط **یک نمونه** از ربات را هم‌زمان اجرا کنید؛ دو پردازهٔ هم‌زمان آپدیت‌ها را از هم می‌دزدند.

## تست‌ها (بدون نیاز به توکن)
```bash
pip install -r requirements-dev.txt
python -m pytest -q
```
تست‌ها شامل منطق بازی (اثبات شکست‌ناپذیری Minimax)، مچ‌میکینگ، جریان کامل ربات با API جعلی و یک تست سرتاسری روی HTTP محلی هستند.

## ساختار پروژه
```
bot/
  bale_api.py      کلاینت سبک async برای API بله (POST JSON به tapi.bale.ai)
  tictactoe.py     منطق دوز + Minimax
  matchmaking.py   صف انتظار + مدیریت بازی‌ها
  keyboards.py     دکمه‌های شیشه‌ای و قرارداد callback_data
  texts.py         متن‌های فارسی
  app.py           هندلرها، رندر تخته، حلقهٔ polling، تایم‌اوت‌ها
  config.py        تنظیمات از .env
tests/             تست‌ها
docs/              سند تحقیق
```

## تنظیمات (`.env`)
| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `BALE_TOKEN` | — | توکن بازو (الزامی) |
| `BALE_API_BASE` | `https://tapi.bale.ai` | آدرس API |
| `POLL_TIMEOUT` | `30` | ثانیهٔ انتظار Long Polling |
| `TURN_TIMEOUT` | `120` | حداکثر زمان هر نوبت (ثانیه) |
| `QUEUE_TIMEOUT` | `180` | حداکثر انتظار در صف (ثانیه) |
| `CPU_DELAY` | `0.7` | مکث کامپیوتر قبل از حرکت (ثانیه) |
| `LOG_LEVEL` | `INFO` | سطح لاگ |

## همیشه‌روشن ماندن روی سیستم شخصی
- **ویندوز:** Task Scheduler (اجرا هنگام ورود، تکرار در صورت خطا) یا NSSM برای تبدیل به سرویس.
- **لینوکس:** یک unit فایل systemd با `Restart=always`:
  ```ini
  [Service]
  WorkingDirectory=/path/to/Bale
  ExecStart=/path/to/Bale/.venv/bin/python -m bot
  Restart=always
  RestartSec=5
  ```
- اگر کامپیوتر Sleep شود ربات قطع می‌شود؛ اگر ربات بیش از ۲۴ ساعت خاموش بماند، بله آپدیت‌های قدیمی را نگه نمی‌دارد.

## قدم‌های بعدی پیشنهادی
1. تست با توکن واقعی و دو حساب بله؛ بررسی رفتار کلاینت‌های قدیمی.
2. ذخیرهٔ آمار برد/باخت در SQLite و جدول امتیازات.
3. لینک دعوت دوست: `ble.ir/<bot>?start=invite_<code>` برای بازی با فرد مشخص.
4. انتخاب بازی نهایی؛ ماژول `tictactoe.py` با هر بازی نوبتی دیگری قابل جایگزینی است.
5. در صورت نیاز به رابط گرافیکی: مینی‌اپ بله (نیازمند میزبانی HTTPS).
